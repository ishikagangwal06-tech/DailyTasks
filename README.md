# ✨ DailyTasks — Your Personal Task Manager

**One task at a time. You've got this!**

DailyTasks is a simple and user-friendly task management web application designed to help users organize their daily activities, manage priorities, and track their progress. With a clean interface and a calming design, DailyTasks makes managing everyday tasks easier and more enjoyable.

## 🌐 Live Demo

🚀 **Live Website:** [DailyTasks](https://dailytasks-gvfo.onrender.com)

💻 **GitHub Repository:** [DailyTasks on GitHub](https://github.com/ishikagangwal06-tech/DailyTasks)

## 📌 Features

- **Task Management:** Create, edit, delete, and manage daily tasks.
- **Task Categories:** Organize tasks into College, Personal, Work, and Other categories.
- **Priority Levels:** Assign priorities to tasks for better organization.
- **Due Dates:** Schedule tasks according to their deadlines.
- **Dashboard:** Get an overview of today's tasks, completed tasks, and upcoming activities.
- **Progress Tracking:** Monitor daily progress as you complete tasks.
- **Calendar:** Keep track of scheduled activities.
- **Reminders:** Stay organized and remember important tasks.
- **Dark Mode:** Switch between light and dark themes.
- **Minimal Interface:** Enjoy a clean, organized, and distraction-free workspace.

## 🛠️ Tech Stack

- **HTML5** — Structures the application.
- **CSS3** — Handles styling, layout, and visual design.
- **JavaScript** — Powers task management and interactive features.
- **Render** — Hosts the live web application.
- **Git & GitHub** — Used for version control and source code management.

## 🚀 Getting Started

You can run DailyTasks locally in just a few steps.

### Prerequisites

- A web browser such as Chrome, Safari, or Firefox.
- Git (optional, if you want to clone the repository).

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/ishikagangwal06-tech/DailyTasks.git
   ```

2. Navigate to the project folder:

   ```bash
   cd DailyTasks
   ```

3. Open `index.html` in your web browser.

No package installation or build process is required for this plain HTML, CSS, and JavaScript project.
